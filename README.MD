## Run Development

### prerequisites
    - node
    - git
    - expo cli

### Clone repo

    git clone https://github.com/bejow/breeder.git

### Install EAS for App Deployment

[Install EAS CLI](https://docs.expo.dev/get-started/set-up-your-environment/?mode=development-build)

### Install Dependencies

yarn install

### Run

    expo start -c
